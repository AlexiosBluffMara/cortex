import torch
import torch.nn as nn
import torch.nn.functional as F

class BitLinear(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.weight = nn.Parameter(torch.empty(out_features, in_features))
        self.bias = nn.Parameter(torch.zeros(out_features))
        nn.init.kaiming_uniform_(self.weight)

    def forward(self, x):
        scale = self.weight.abs().mean().clamp_min(1e-5)
        w_q = (self.weight / scale).round().clamp(-1, 1)
        a_scale = x.abs().amax(dim=-1, keepdim=True).clamp_min(1e-5) / 127.0
        x_q = (x / a_scale).round().clamp(-128, 127)
        return F.linear(x_q, w_q, None) * a_scale * scale + self.bias

def fibonacci(n):
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

In quantum mechanics, the principle of superposition states that any quantum system can exist in multiple states simultaneously until it is measured. This is famously illustrated by Schrodinger's cat thought experiment, in which a cat in a sealed box is considered to be both alive and dead until the box is opened and the state of the cat is observed. Modern quantum computers exploit superposition by manipulating qubits, which can represent both zero and one at the same time, enabling certain algorithms to outpace any classical algorithm by exponential factors.

A transformer language model is a sequence-to-sequence neural network that uses attention as its primary computational primitive. Each layer applies multi-head self-attention followed by a feedforward sublayer, with residual connections and layer normalization. The attention mechanism allows each token to gather information from all other tokens in the context, weighted by learned compatibility scores. Modern decoder-only transformers, such as the GPT family, predict the next token in a sequence by attending only to previous tokens. Pretraining on large text corpora produces broadly capable language models that can be further fine-tuned on specific tasks.
