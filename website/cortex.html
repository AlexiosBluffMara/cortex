Watch your brain
respond to any video.

A multimodal brain-response analysis system, built on Meta's TRIBE v2 brain foundation model and a Kimi-assisted Three.js viewer. Upload a clip — when Seratonin is online, get a 3D cortical-activation map plus four parallel narrations from four very different readers anchored to real Illinois institutions: an ISU student, a Carle/BroMenn patient, a Northwestern Memorial / RUSH clinician, and a Chicago ML scientist.

The Brain Cinema — in one paragraph

Picture a movie theatre. Your brain is the audience: 20,484 people in 20,484 assigned seats, each responsible for a specific job — seeing faces, recognising voices, feeling suspense, processing language. The movie is whatever you upload. TRIBE v2, Meta's brain foundation model, is the high-speed sensor system in every seat — twice per second, it predicts how excited each audience member is going to get, three to five seconds before their reaction visibly peaks. Gemma 4 is the panel of four critics in the back booth: after the screening, all four read the same audience-reaction printout and write their own takes — an ISU student, a Carle / BroMenn patient, a Northwestern Memorial / RUSH clinician, and a Chicago ML scientist. You see all four side-by-side and pick the voice that sounds like your brain.

"Twenty thousand seats. One movie. Four critics. About three minutes."

Architecture — how it actually runs right now

   ┌──────────────────────────────────────────────────────────────────┐
   │ Browser / phone                                                  │
   │   ↓ https://redteamkitchen.com                                    │
   ├──────────────────────────────────────────────────────────────────┤
   │ Seratonin — Windows · RTX 5090 · 32 GB VRAM                      │
   │                                                                  │
   │   FastAPI webapp  (port 8765) — serves HTML + API directly       │
   │     ├─ TRIBE v2 (PyTorch on CUDA, ~6 GB VRAM)                    │
   │     │   → 20,484-vertex BOLD prediction at 2 Hz                  │
   │     │                                                            │
   │     └─ 4× narrate (parallel, in queue)                           │
   │         ↓                                                        │
   │   Inference router (port 8766)                                   │
   │     ├─→ Local Ollama (Gemma 4 E4B / 26B / 31B)                   │
   │     └─→ OpenRouter free tier (cloud failover, $0/token)          │
   ├──────────────────────────────────────────────────────────────────┤
   │ Optional cloud TRIBE worker — funded path, not default           │
   │   ↳ only used when explicitly configured and selected            │
   └──────────────────────────────────────────────────────────────────┘

The live demo depends on Seratonin being online because TRIBE v2 runs on the local RTX 5090. If that PC is unavailable, the static site and gallery can still load, but new live brain-response scans need a configured cloud TRIBE worker. Narration can fall back to OpenRouter's free Gemma endpoints when local Ollama is unavailable.

The viewer

A WebGL/Three.js scene with per-vertex animation, written with Kimi K2.6 via the Nous Portal during the Cortex viewer sprint. This is the piece the public demo needs to show: what the model predicts the brain experiences while seeing an image, text prompt, audio clip, or video.
