What ABM does

Alexios Bluff Mara LLC partners with Illinois State University on applied AI and computational neuroscience research. The work is hardware-flexible by design: the same code path runs on a single RTX 5090 sitting under a desk, on a Google Cloud Run L4 instance for burst capacity, and — through ACCESS-CI partnerships at UIUC and similar institutions — on national HPC nodes when the experiment demands them. Open-source where possible. Local-first by default.

"From a single Blackwell card to an HPC partition — same code, different horsepower. The research question dictates the hardware, not the other way around."

Kaggle · Gemma 4 Good — Health & Sciences track
Cortex: accessible brain imaging with a $2,600 GPU.
Clinical fMRI costs $5,000/scan and requires a radiologist. Cortex runs the same predictive model for <$0.01 and narrates the result in plain language. Built on Meta TRIBE v2 + Google Gemma 4, Apache-2.0.

Nous Research × Kimi — Creative track
Mercury: a personal AI agent built from a Hermes-fork brain.
One model instance running on the local 5090, reachable from terminal, Discord bot, and a phone-friendly web dashboard over Tailscale. Hermes-fork brain on local Ollama (Gemma 4) with OpenRouter free-tier as cloud overflow. MIT license.
